SETUP GUIDE Step by step

STEP 1: FILL IN YOUR VALUES (this page)

  1. Set your keybind above (click the box, press your combo like Ctrl+Shift+F5)
  2. Fill in the Lookup fields you use every time (hearing date, time, type)
  3. Fill in the Disposition fields (plea, disposition, fine, cost, etc.)
  4. Check the boxes if you want it to auto-press Enter / PF12
  5. Everything saves automatically in your browser

STEP 2: INSTALL AUTOHOTKEY (one time only)

  1. Go to autohotkey.com
  2. Click Download — get AutoHotkey v2 (not v1)
  3. Run the installer, click Next through everything
  4. That's it — no restart needed

STEP 3: DOWNLOAD YOUR SCRIPT

  1. Click the green DOWNLOAD AHK SCRIPT button on this page
  2. Save the uadrci_autofill.ahk file somewhere (Desktop is fine)
  3. If you change any values on this page, download a new script to pick up the changes

STEP 4: RUN THE SCRIPT

  1. Double-click the .ahk file — a green H icon appears in your system tray (bottom-right near the clock)
  2. The script is now running in the background
  3. To stop it: right-click the H tray icon → Exit, or press Ctrl+Shift+Q

STEP 5: USE IT IN QUICK3270

  1. Open Quick3270 and navigate to the UADRCI screen
  2. Press your keybind — tray says "ARMED"
  3. Click into the CASE field and type the 7-character case number
  4. The moment you type the 7th character, the script automatically fills hearing date, time, type, plea, disposition, fine, cost — everything you configured
  5. Review the screen, then press PF12 to update (or the script presses it if you checked that box)
  6. The script auto-disarms after filling — press your keybind again for the next case

TROUBLESHOOTING

  • "Cannot connect to Quick3270" — make sure Quick3270 is open and connected before pressing the keybind
  • Nothing happens when I press the keybind — check the system tray for the green H icon. If it's not there, double-click the .ahk file again
  • Fields fill in the wrong spot — open the Advanced section on this page and update the row/col coordinates (click each field in Quick3270 and read the bottom-left status bar)
  • Changed values but not working — you need to download a NEW .ahk script after changing values, then double-click it (it replaces the old one automatically)
