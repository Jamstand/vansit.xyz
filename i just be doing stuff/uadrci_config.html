SETUP GUIDE Step by step

STEP 1 — Configure Your Values

  1. Pick your keybind above (F6, Ctrl+F5, whatever you prefer)
  2. Fill in the Lookup + Disposition fields with the values you use most
  3. Optionally save as a template (e.g. "Guilty Standard") so you can switch between case types
  4. Paste your case numbers into the Case List section for batch tracking

STEP 2 — Install AutoHotkey v2 (One Time Only)

  1. Go to autohotkey.com and download AutoHotkey v2 (not v1)
  2. Run the installer — click Next through everything, then Finish

STEP 3 — Download & Set Up

  1. Click DOWNLOAD ALL — you'll get 2-3 files:
    • uadrci_orchestrator.ahk — the brain (runs on your desktop)
    • uadrci_bridge.mac — the hands (runs inside Quick3270)
    • case_list.txt — your case numbers (if you entered any)
  2. Open uadrci_bridge.mac in Notepad → Ctrl+A, Ctrl+C
  3. In Quick3270: Tools → Macros → New Macro → Ctrl+V → Save as uadrci_bridge
  4. Assign a hotkey: Tools → Customize → Keyboard → find your macro → assign Ctrl+F8
  5. Copy case_list.txt to %APPDATA%\UADRCI\ folder (the AHK creates this folder automatically)

STEP 4 — Run It!

  1. Double-click uadrci_orchestrator.ahk — a tooltip shows "Case 1/45" (or however many you loaded)
  2. Go to the UADRCI screen in Quick3270
  3. Press your keybind — the orchestrator writes the case data, triggers the bridge macro, and all fields fill in
  4. It auto-advances to the next case. Press the keybind again for the next one
  5. Use F7 to skip a case, F5 to go back, Ctrl+Shift+S for stats

The orchestrator remembers your progress even if you close and reopen it.

TROUBLESHOOTING

  • "Cannot connect to Quick3270"
    Make sure Quick3270 is open AND connected to the mainframe before pressing the keybind. The script can't fill fields if Quick3270 isn't running.
  • Nothing happens when I press the keybind
    Look for the green H icon in your system tray (bottom-right by the clock). If it's not there, double-click the .ahk file again. If Windows asks how to open it, pick AutoHotkey.
  • I see the green H but the keybind still does nothing
    Try right-clicking the green H → Exit, then double-click the .ahk file again. Some keybinds (like plain F6) might conflict with Quick3270 — try a different combo like Ctrl+F6.
  • The fields fill in the wrong spot
    The row/column numbers might be off. On this page, open the "Advanced" section and update the coordinates. To find them: in Quick3270, click a field and look at the bottom-left of the window — it shows the row and column numbers.
  • I changed values but it's still using the old ones
    You need to download a NEW .ahk script every time you change values on this page. Click the green button again, then double-click the new file (it replaces the old script automatically).
  • AutoHotkey doesn't work at all on my computer
    Try the Quick3270 native macro instead — it doesn't need AutoHotkey. In Quick3270 go to Tools → Macros → New Macro, paste the code from uadrci.mac, and save. Then run it from Tools → Macros → Run. It uses popup boxes instead of auto-filling, but it still saves time.
