SETUP GUIDE Step by step

STEP 1 — Set Up Your Values (Do This First!)

Scroll up on this page and fill in the fields you want the macro to auto-type for you.

  1. Pick your keybind — scroll up to the HOTKEY section, click the box, and press the key combo you want (like F6, or Ctrl+F5, or whatever you prefer)
  2. Fill in the Lookup fields — hearing date, hearing time, type (these are the fields that go in BEFORE you press Enter on the real screen)
  3. Fill in the Disposition fields — case action, continuance, plea, disposition, sentence code, fine, cost
  4. Check the boxes if you want the macro to automatically press Enter (for lookup) or PF12 (for update)
  5. Don't worry about saving — everything saves automatically in your browser

STEP 2 — Install AutoHotkey (One Time Only)

AutoHotkey is a free program that lets you create keyboard shortcuts. You only need to install it once.

  1. Open your browser and go to autohotkey.com
  2. Click the big Download button
  3. Make sure you pick AutoHotkey v2 (not v1 — v1 won't work)
  4. Run the installer — just click Next through everything, then Finish
  5. That's it! No restart needed. You won't see anything new on your desktop yet — that's normal

STEP 3 — Download Your Script

This page builds a custom script with your values baked in. Every time you change values, you need to download a fresh copy.

  1. Scroll up and click the big green DOWNLOAD AHK SCRIPT button
  2. Your browser will download a file called uadrci_autofill.ahk
  3. Save it somewhere easy to find — your Desktop or Documents folder

Remember: if you change any values on this page later, you need to click the green button again to get an updated script!

STEP 4 — Run the Script

  1. Double-click the uadrci_autofill.ahk file you just downloaded
  2. Look at the bottom-right corner of your screen near the clock (the system tray). You should see a small green H icon appear
  3. If you see the green H — the script is running! It's sitting in the background waiting for your keybind
  4. If Windows asks "How do you want to open this file?" — choose AutoHotkey
  5. To stop the script later: right-click the green H icon → click Exit

Tip: you can click the little ^ arrow in the system tray to see hidden icons if you don't see the green H right away.

STEP 5 — Use It!

  1. Open Quick3270 and go to the UADRCI screen like you normally would
  2. Type your case number in the CASE field (7 characters)
  3. Press your keybind — you'll see a notification pop up near the clock that says "Filling fields..."
  4. The script automatically fills in all the other fields — hearing date, time, type, plea, disposition, fine, cost, everything you configured
  5. Look over the screen to make sure everything looks right
  6. Press PF12 to update (or the script does it for you if you checked that box)
  7. For the next case: type a new case number, press your keybind again — that's it!

That's the whole workflow: type case number → press keybind → done. Repeat for each case.

TROUBLESHOOTING

  • "Cannot connect to Quick3270"
    Make sure Quick3270 is open AND connected to the mainframe before pressing the keybind. The script can't fill fields if Quick3270 isn't running.
  • Nothing happens when I press the keybind
    Look for the green H icon in your system tray (bottom-right by the clock). If it's not there, double-click the .ahk file again. If Windows asks how to open it, pick AutoHotkey.
  • I see the green H but the keybind still does nothing
    Try right-clicking the green H → Exit, then double-click the .ahk file again. Some keybinds (like plain F6) might conflict with Quick3270 — try a different combo like Ctrl+F6.
  • The fields fill in the wrong spot
    The row/column numbers might be off. On this page, open the "Advanced" section and update the coordinates. To find them: in Quick3270, click a field and look at the bottom-left of the window — it shows the row and column numbers.
  • I changed values but it's still using the old ones
    You need to download a NEW .ahk script every time you change values on this page. Click the green button again, then double-click the new file (it replaces the old script automatically).
  • AutoHotkey doesn't work at all on my computer
    Try the Quick3270 native macro instead — it doesn't need AutoHotkey. In Quick3270 go to Tools → Macros → New Macro, paste the code from uadrci.mac, and save. Then run it from Tools → Macros → Run. It uses popup boxes instead of auto-filling, but it still saves time.
